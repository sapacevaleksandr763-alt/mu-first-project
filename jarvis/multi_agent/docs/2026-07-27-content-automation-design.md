# Спецификация: Автоматизация контента для @nasledieariev

> Дата: 2026-07-27
> Статус: в реализации
> Подход: A — Node.js сервис на VPS (полная автономность)

---

## Цель

Автоматическая генерация и публикация постов в Telegram-канал @nasledieariev 4 раза в неделю без участия человека. В конце месяца — анализ метрик и автогенерация нового контент-плана.

## Архитектура

```
content-plan.json ──→ scheduler.js (node-cron)
                          │
                    ┌─────┴─────┐
                    │ По расписанию │
                    └─────┬─────┘
                          ↓
                   content-generator.js
                   (OpenAI API → текст поста)
                          ↓
                   generate-image.js
                   (DALL-E → картинка)
                          ↓
                   publish.js
                   (Telegram Bot API → канал)
                          ↓
                   logger.js
                   (лог публикации → data/publish-log.json)
                          ↓
                   analytics.js (конец месяца)
                   (метрики → новый content-plan.json)
```

## Расписание публикаций

| День | Время (МСК) | Тип поста | Описание |
|------|-------------|-----------|----------|
| Пн   | 10:00       | Инфо-пост | Статья/разбор по теме канала + ссылка на сайт |
| Ср   | 10:00       | Визуал    | Карточка/инфографика с DALL-E |
| Пт   | 10:00       | Практика  | Обряд, практика, руна дня + ссылка на инструмент сайта |
| Вс   | 10:00       | Вовлечение | Опрос, обсуждение, CTA на сайт |

## Тон канала

**Мудрый наставник.** Глубокий, спокойный, с отсылками к первоисточникам. Как волхв, который делится знаниями. Без пафоса, без кликбейта, без «подписывайся!!!». Уважительный к традиции, но доступный современному читателю.

## Стратегия привлечения аудитории

Каждый пост содержит:
1. Ценный контент (человек получает пользу даже без перехода)
2. Ненавязчивый CTA — ссылка на сайт (конкретную страницу: квиз, календарь, рунное гадание)
3. Хэштеги для органического поиска

## Автогенерация нового плана

В последнее воскресенье месяца analytics.js:
1. Собирает метрики опубликованных постов (просмотры, реакции)
2. Определяет топ-3 темы по вовлечённости
3. Генерирует новый content-plan.json на следующий месяц через OpenAI API
4. Отправляет отчёт владельцу в личку бота
