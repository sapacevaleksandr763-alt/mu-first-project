# Отчёт агента: Дизайнер
**Дата:** 2026-07-15
**Тема:** Визуал для поста "5 ошибок малого бизнеса при внедрении ИИ"
**Статус:** Завершён

## Дизайн-бриф

### Концепция

Метафора "сломанный механизм": пять шестерёнок, которые не стыкуются друг с другом. Центральная шестерня — с символом AI/мозга — пытается крутить систему, но зубцы не совпадают. Это передаёт основную мысль поста: ИИ не работает, если бизнес-процессы не подготовлены. Настроение — тревожно-аналитическое, без паники, но с ощущением "тут что-то не так".

Каждая сломанная шестерня визуально отсылает к одной из пяти ошибок: одна ржавая (хаос в данных), одна золотая но без зубцов (внедрение без задачи), одна с трещиной (замена людей) и т.д. Фон — тёмный, чтобы карточка выделялась в ленте Telegram.

### Палитра

| Цвет | HEX | Назначение |
|------|-----|-----------|
| Глубокий тёмно-синий | `#0D1B2A` | Фон — задаёт серьёзность |
| Электрический голубой | `#1B9AAA` | Акцент AI-элементов — технологичность |
| Тёплый оранжевый | `#E07A5F` | Ошибки, сломанные элементы — сигнал тревоги |
| Приглушённый белый | `#E8E8E4` | Контурные линии, мелкие детали |
| Стальной серый | `#415A77` | Шестерни, механизм — нейтральная основа |
| Мягкий красный | `#D64045` | Точечные акценты: трещины, искры, X-метки |

### Стиль

**Flat illustration с элементами изометрии.** Почему:

1. Flat хорошо масштабируется в маленьких превью Telegram (карточка часто видна как 300x300px в ленте)
2. Изометрия добавляет глубину без перегрузки — шестерни выглядят объёмно, но читаемо
3. Этот стиль DALL-E 3 генерирует стабильно и качественно — без артефактов, которые часто появляются при запросе фотореализма
4. Серьёзный, но не корпоративно-стерильный — подходит для аудитории предпринимателей и фрилансеров

### Композиция

- **Центр:** крупная шестерня с символом нейросети/мозга внутри, слегка наклонена — показывает нестабильность
- **Вокруг центра:** 4–5 шестерёнок поменьше, расположенных по кругу. Зубцы не совпадают — видно, что механизм заклинило
- **Нижняя треть:** оставлена относительно свободной — сюда потом ляжет текстовый оверлей с заголовком поста
- **Фон:** градиент от `#0D1B2A` к `#1B2838`, с лёгкой сеткой или схематичными линиями (blueprint-стилистика)
- **Акценты:** мелкие оранжевые и красные искры/X-метки в местах, где шестерни не стыкуются — визуальный "конфликт"

## Рекомендации

### Что НЕ включать в промпт

- **Текст на русском** — DALL-E 3 генерирует кириллицу с ошибками в 90%+ случаев. Любой текст на картинке будет мусорным
- **Текст на английском** — тоже лучше избегать: даже латиница часто искажается. В промпте явно указано "no text, no letters, no words"
- **Цифру "5"** — не просить DALL-E нарисовать цифру, она может получиться нечитаемой или дублироваться
- **Конкретные лица людей** — ненужный риск артефактов, для этой темы абстрактная метафора сильнее

### Как добавить текст поверх

1. **Figma** (основной инструмент Алекса) — импортировать сгенерированное изображение, добавить текстовый слой с заголовком "5 ошибок малого бизнеса при внедрении ИИ" в нижней трети
2. **Рекомендуемый шрифт:** Inter Bold или Montserrat Bold — нейтральные, читаемые на маленьких экранах
3. **Размер заголовка:** 48–64px при 1792x1024
4. **Подложка под текст:** полупрозрачный чёрный прямоугольник (opacity 60–70%) в нижней части — обеспечит контраст
5. **Экспорт:** PNG, качество максимальное, Telegram сожмёт сам при загрузке
